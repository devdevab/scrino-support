# Scrino support

Public support and privacy pages for Scrino, a free macOS window screenshot app.

- [Support](https://devdevab.github.io/scrino-support/)
- [Privacy policy](https://devdevab.github.io/scrino-support/privacy.html)
- [Contact support](https://github.com/devdevab/scrino-support/issues/new)

Scrino has no in-app purchases, subscriptions, ads, accounts, analytics, or screenshot uploads. This repository contains the public website, not the application source.
